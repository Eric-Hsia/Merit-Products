# 规格参数

## 通用规格

| 参数 | 数值 |
|------|------|
| 供电电压 | 3.3V ± 5% |
| 工作电流 | 5 mA（典型值） |
| 休眠电流 | 10 µA |
| 工作温度 | -40°C 至 +85°C |
| 存储温度 | -40°C 至 +125°C |
| 接口 | I²C (400 kHz) / SPI (8 MHz) |

## 物理尺寸

- **封装**：LGA-24
- **尺寸**：5.0mm × 5.0mm × 1.1mm
- **重量**：约 50 mg

## 引脚定义

| 引脚 | 名称 | 描述 |
|------|------|------|
| 1 | VCC | 3.3V 电源供电 |
| 2 | GND | 地 |
| 3 | SCL/SCK | I²C 时钟 / SPI 时钟 |
| 4 | SDA/MOSI | I²C 数据 / SPI 数据输入 |
| 5 | MISO | SPI 数据输出（I²C：悬空） |
| 6 | CS | 片选（I²C：悬空） |
| 7 | INT1 | 中断引脚 1 |
| 8 | INT2 | 中断引脚 2 |

## 通信协议

### I²C 接口
- **地址**：0x68（默认）
- **时钟速度**：最高 400 kHz（快速模式）
- **数据格式**：小端模式

### SPI 接口
- **模式**：CPOL=0, CPHA=0（模式 0）
- **时钟速度**：最高 8 MHz
- **位序**：MSB 在前

## 校准

IMU10A 需要校准以获得最佳性能：

1. **加速度计**：六位置校准
2. **陀螺仪**：静态偏置校准
3. **磁力计**：硬铁/软铁补偿
4. **气压计**：海平面参考设置

详细校准步骤请参考软件文档中的校准指南。
