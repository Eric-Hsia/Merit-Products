merit-lsm6dso-6DoF

概述
----

**merit-lsm6dso-6DoF** 是一款高性能开发板，专为快速原型验证而设计。
板载强劲的 MCU、Wi-Fi/蓝牙模块及丰富的外设接口，帮助您快速启动项目。
