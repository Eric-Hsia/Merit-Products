概述
----

**merit-IMU10A** 是一款紧凑型传感器模块，专为物联网边缘应用设计。
集成多种环境传感器，支持 I2C/SPI/UART 通信接口。

规格一览
--------

.. list-table::
   :widths: 30 70
   :header-rows: 1

   * - 参数
     - 值
   * - 传感器类型
     - 温度、湿度、气压
   * - 通信接口
     - I2C / SPI / UART
   * - 供电电压
     - 3.3 V
   * - 工作温度范围
     - -40 °C ~ +85 °C
